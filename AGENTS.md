# DevDigest — agent instructions

Course-starter app: import GitHub PR, run AI review. NOT an npm workspace monorepo —
5 standalone packages, own `package.json`+lockfile each, linked via tsconfig path
aliases + shared Zod contracts, not published modules.

## Packages

| Dir | Pkg | Stack | Port |
|---|---|---|---|
| `server/` | `@devdigest/api` | Fastify 5, Drizzle ORM + Postgres/pgvector, Zod, Octokit, Anthropic/OpenAI SDKs, ast-grep/dependency-cruiser/graphology (repo-intel indexer) | 3001 |
| `client/` | `@devdigest/web` | Next.js 15 (App Router), React 19, Tailwind 4, TanStack Query, next-intl | 3000 |
| `reviewer-core/` | `@devdigest/reviewer-core` | pure engine: diff→prompt→LLM→findings, zod only, no DB/FS side effects except injected LLMProvider | — |
| `e2e/` | `@devdigest/e2e` | deterministic browser e2e (agent-browser), no LLM | — |
| `server/src/vendor/shared` | `@devdigest/shared` | Zod contracts shared by server+client+reviewer-core | — |

Flow: client → REST → server → Postgres. server clones+indexes repo (repo-intel)
→ reviewer-core builds prompt (diff+repo map) → LLM → grounding gate (drops
hallucinated line refs) → findings persisted.

## Commands

Root: `./scripts/dev.sh` (Postgres up, env files, deps, migrate, seed, launch both). Flags: `--no-seed` `--no-client` `--db-only`.

`server/`: `pnpm dev` (tsx watch :3001) · `pnpm build` · `pnpm typecheck` · `pnpm test`
(vitest; split `pnpm exec vitest run --exclude '**/*.it.test.ts'` unit vs `.it.test` DB-integration)
· `pnpm db:generate` (drizzle-kit) · `pnpm db:migrate` · `pnpm db:seed`

`client/`: `pnpm dev` (:3000) · `pnpm build` · `pnpm start` · `pnpm typecheck` · `pnpm test` (vitest)

`reviewer-core/`: `pnpm typecheck` · `pnpm test` (`--passWithNoTests`)

`e2e/`: see `e2e/README.md`, run via `scripts/e2e.sh`

No lint script/config in repo (no eslint/prettier config files) — don't invent one, don't add lint step to CI.

CI: path-filtered GH Actions — `client.yml`, `server-unit.yml`, `server-integration.yml` (needs Docker/testcontainers), `reviewer-core.yml`, `e2e-web.yml`.

## Conventions

- Commits: Conventional Commits with scope, e.g. `feat(reviews): ...`, `fix(db): ...`, `docs(insights): ...`, `chore: ...`. Merge commits kept as-is (`Merge pull request #N from user/branch`).
- Branches (from PR merges seen): `<topic>` or `<course-id>-<topic>` e.g. `hw_1_findings`, `mp-l01`, `integration/all-features`.
- Client component dirs: kebab-case folder (`diff-viewer/`, `app-shell/`), barrel `index.ts`, component file PascalCase (`DiffViewer/`, `AppShell.tsx`), colocated `constants.ts` / `helpers.ts` / `styles.ts` per component dir.
- Server: schema split by domain under `server/src/db/schema/*.ts` (`repos.ts`, `pulls.ts`, `reviews.ts`, `runs.ts`, `agents.ts`, `ci.ts`, `eval.ts`, `knowledge.ts`, `ops.ts`, `repo-intel.ts`, `skills.ts`, `_shared.ts` for shared column helpers), aggregated in `schema.ts`.
- `reviewer-core` stays pure: no DB/FS/GitHub imports, only injected `LLMProvider`.

## Windows setup note

`CLAUDE.md` files in this repo (root + `client/`, `server/`, `reviewer-core/`,
`e2e/`) are real git symlinks → `AGENTS.md`, single source of truth. On
Windows, a fresh clone flattens these into plain text files containing the
literal string `AGENTS.md` (breaking Claude Code) unless BOTH are true
before cloning: Developer Mode is on (`Settings > Privacy & Security > For
developers`) AND `git config --global core.symlinks true` is set. If you
already cloned without these, fix locally: enable both, then
`git rm CLAUDE.md server/CLAUDE.md client/CLAUDE.md reviewer-core/CLAUDE.md e2e/CLAUDE.md && git checkout -- CLAUDE.md server/CLAUDE.md client/CLAUDE.md reviewer-core/CLAUDE.md e2e/CLAUDE.md`.

## Read when

- Server API routes/contracts, repo-intel pipeline internals → `server/README.md`
- Client routing/data-fetching conventions → `client/README.md`
- e2e flow specs (what's covered) → `e2e/README.md`, `e2e/specs/`
- Session gotchas/non-obvious facts for a package → `<package>/INSIGHTS.md` if present
- Anything else project-wide not covered above → `docs/`

## Do not touch

- `server/src/db/migrations/*.sql` and `server/src/db/migrations/meta/**` — generated by `drizzle-kit generate`; never hand-edit, never renumber. New schema change → edit `server/src/db/schema/*.ts` then run `pnpm db:generate`.
- `*/pnpm-lock.yaml`, `e2e/package-lock.json`, `reviewer-core/package-lock.json` — never hand-edit; regenerate via `pnpm install`/`npm install` only.
- `client/next-env.d.ts` — Next.js-generated, do not edit.
- `server/src/vendor/shared`, `client/src/vendor/*` — vendored/shared copies; treat as read-only unless task is explicitly about updating the shared contract source.
- `skills-lock.json`, `.claude/skills/**` — skill system state, don't hand-edit lock file.
- `server/.env`, `client/.env` — local secrets, never commit/read into output.
